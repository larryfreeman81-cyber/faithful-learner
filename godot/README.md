# Faithful Learner — Godot game project

This is the source foundation for the next-generation game, separate from the current GitHub Pages prototype.

## Open and run

Install Godot 4.3 or later. In the Godot Project Manager, import this `godot/project.godot` file and run the project. Keyboard controls: A/D or arrow keys to walk, E or Space to discover. Progress is saved locally.

## Production status

This is a **source scaffold and playable prototype**, not a polished commercial-quality game. It currently has procedural placeholder scenery, no commissioned high-definition artwork, no sound, and no mobile touch controls in the Godot build. Browser export has **not** been built or tested. The existing `index.html` GitHub Pages game remains the live website.

Next milestones: illustrated environment asset pipeline, character animation, touch controls, contextual wildlife behaviors, layered exploration quests, three learning profiles, accessibility testing, HTML5 export, and performance QA.
